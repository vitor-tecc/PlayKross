The host can send the creation snapshot before returning a reservation; discarding it prevented prompt recognition of a later removal. Two new tests reproduced creation-before-grant and creation-and-removal-before-grant, then passed after the controller retained observations during the bounded reservation request and matched them only to its successful create-only grant. Unknown snapshot IDs never grant ownership.
